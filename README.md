# مكتبتي

مرجع شخصي للأحاديث والآثار وأقوال العلماء الواردة في كتبي وأبحاثي، مع تخريج كل نص وحكمه وموضعه في الكتاب.

- يعمل من المتصفح مباشرة، ويمكن تثبيته على الجوال (إضافة إلى الشاشة الرئيسية)، ويعمل دون اتصال بعد أول فتح.
- الكتب المضافة حاليًا: «الجامع في الخشوع».

## للمطوّر
- `tools/extract.py`: يستخرج البطاقات من نص الكتاب: `python3 tools/extract.py book.txt cards.json`
- `tools/app.html`: قالب الواجهة، و`tools/data.json`: البيانات المضغوطة.
- البناء: استبدال `/*DATA*/` في القالب بمحتوى data.json ثم تغليفه في `index.html`.
- نص الكتاب الكامل لا يُرفع إلى المستودع.
